## Rust changed me as a developer

- 原文链接: [Rust changed me as a developer](https://blog.startifact.com/posts/how-rust-changed-me/)
- HN链接: [Hacker News讨论](https://news.ycombinator.com/item?id=50522563)

After more than six years with Rust, the author explains how it changed the way he builds software. His main point is that learning a different language can change how you think, not just how you write code.

Rust’s enums let one type hold different kinds of data, such as either a human or a cat. The compiler checks that the code handles every possible case. This can be simpler than building a shared interface when the list of cases is small and known. Rust can also prepare code for a specific type before the program runs, avoiding some checks during use. The author now uses types to help plan software, much as tests and clear notes help shape a design. His biggest surprise was macros, which create code before the program runs. With Serde, a few added lines can create the code needed to save and load data. With Clap, a type definition can describe command-line options and produce help text. Rust’s ownership rules also push developers to think carefully about which parts of a program control and change data. These rules can be hard to learn, but the author says they can make the overall design easier to follow. For linked data, such as trees, he often stores items together in an array and connects them using numbers instead of direct links. This approach can also make memory use and data access faster. His biggest lesson is that better speed does not just save time; it can make new kinds of software possible.

## Grazing sheep in fields with solar arrays

- 原文链接: [Grazing sheep in fields with solar arrays](https://news.cornell.edu/stories/2026/10/sheep-grazing-solar-fields-offers-farmers-economic-ecological-gains)
- HN链接: [Hacker News讨论](https://news.ycombinator.com/item?id=50520182)

Cornell researchers studied how sheep can share fields with solar panels, helping farmers earn money while keeping grass down. Two new papers explore the effects on insects and offer a tool for managing sheep.

The first team tested different numbers of sheep at one solar farm in New York over three years. With two sheep per hectare, helpful insects were 38% more common than in areas where machines cut the grass. Much of that rise came from honey bees, whose numbers increased by 83%. With four sheep per hectare, insect numbers were similar to those in the machine-cut areas. Those four sheep also kept the grass shorter than two sheep did. Eight sheep per hectare gave the best grass control, and the sheep stayed healthy. But at that level, honey bee numbers fell by 45%. The finding shows a clear trade-off between keeping grass down and supporting helpful insects.

The second team built a spreadsheet tool to help farmers plan their sheep businesses. It uses costs, expected income, grass supply, and the farmer’s target number of sheep. It helps farmers decide when to buy or sell animals. It can also help solar companies create contracts that work better for farmers. One sheep business already uses the tool when bringing new farmers into its program. The wider promise is simple: farmers can get paid to feed their sheep on land, rather than paying to use it.

## Jiff 1.0: A datetime library for Rust

- 原文链接: [Jiff 1.0: A datetime library for Rust](https://burntsushi.net/jiff/)
- HN链接: [Hacker News讨论](https://news.ycombinator.com/item?id=50519744)

Jiff 1.0 is a date and time library for Rust that aims to make common mistakes harder to make. It already runs in tools such as Cargo, uv, and Nushell.

Its main idea is to put time zones at the center of working with dates. A timestamp marks one exact moment, while a local date and time describe what people see on their clocks. Jiff can join these with a time zone, such as New York or Tokyo. This matters because a time zone includes rules for clock changes, not just a fixed number of hours ahead or behind UTC. When clocks change, some local times happen twice, while others never happen.

By default, Jiff chooses the first copy of a repeated time and moves forward past a missing time. Developers can change those choices or ask for an error instead. Jiff also knows that “tomorrow at the same time” can be 23 or 25 hours away. Its `Span` type keeps calendar units, such as months and days, separate from hours and minutes. That means adding one month is not treated as adding a fixed number of seconds.

The library reads and writes common date formats, plus friendly time lengths such as “2 hours, 30 minutes.” Support for other languages and calendars comes through the separate ICU4X library. The author plans to keep the 1.0 design stable unless a serious problem appears.

## Spamhaus new email sender requirements in November

- 原文链接: [Spamhaus new email sender requirements in November](https://www.spamhaus.org/sender-guidelines/)
- HN链接: [Hacker News讨论](https://news.ycombinator.com/item?id=50523784)

Spamhaus is gradually adding stricter email sender checks starting in November 2026. Email services use its blocklists to help stop spam, so senders with poor setups risk having their mail blocked.

Every sending IP address must have a reverse DNS record that points to a full server name. That name must also point back to the same IP address. The server’s greeting, called HELO or EHLO, must use a steady name that points to its sending address. Names like “localhost” and default hosting company names are not acceptable greetings. IPv6 senders also need valid reverse DNS and an address block of at least /64.

The wider guidelines require SPF records to show which servers may send email for a domain. Each outgoing message must carry a valid DKIM signature to help prove where it came from. Senders must also publish a DMARC policy, which tells receiving services how to handle mail that fails identity checks. Mailing list members must confirm their address before receiving further emails. Bought or collected address lists can contain spam traps, which are addresses used to catch unwanted mail. Senders should increase sending slowly and must not use services that create fake opens or replies. Failed deliveries must stay below five percent, and commercial senders must offer easy ways to leave their lists and act within two days. Spamhaus provides tools to check server greetings, DNS settings, and whether an address or domain is listed.

## Squircles

- 原文链接: [Squircles](https://linebender.org/wiki/curves/squircle/)
- HN链接: [Hacker News讨论](https://news.ycombinator.com/item?id=50515151)

A squircle is a shape between a square and a circle. This article looks at how Apple, Figma, and web browsers build these shapes.

There is no single rule for drawing a squircle.
One well-known version is called a superellipse.
Changing one number in its rule makes it move from a circle toward a square.
Some squircles use one curved line all the way around.
Others join straight sides to curved corners.
Straight sides let a shape become wider or taller without changing its corners.
Apple brought more attention to squircles when it changed its app icons in 2013.
Its shape has flat sides, rather than being a simple superellipse.
The article points out tiny errors in Apple's shape, though they are hard to see.
Figma's version fixes some of those errors, but its curves still have joins that are not fully smooth.
The key issue is not just whether the lines meet, but whether their bending changes smoothly.
The article explains that superellipses and another curve called a clothoid can provide these smoother joins.
CSS now defines squircle corners through `corner-shape`, and the article shows settings that look close to Apple's design.
