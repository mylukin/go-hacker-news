First, let’s talk about Kobo e-readers and a new open-source platform called Cobalt. With Cobalt, users of the Kobo Clara BW can now install a launcher and app store, making it possible to download, update, and remove various apps over Wi-Fi. Each app runs as its own process and must ask permission to use the network or storage, making the system safer. Apps are signed to make sure they are safe before running. If you restart your Kobo, it goes back to normal as a regular e-reader, so nothing is permanent.

There are already many apps, like an arXiv reader for research papers, Sudoku, Morse code flasher, a Hacker News client, RSS reader, eBook reader for Project Gutenberg, a terminal, daily news, todo list, tic-tac-toe, and more. The apps are all designed for e-ink screens and written in Rust, using a simple SDK. Developers can make new apps easily and submit them with pull requests.

To install Cobalt, you need a Kobo Clara BW and a USB connection for the first setup. After that, everything works wirelessly. Only the Clara BW is fully supported now, and Cobalt is not made by Kobo itself.

In the Hacker News comments, many users were excited about more features for e-readers. People liked the open-source nature and Rust for safety. Some loved the idea of reading arXiv papers or browsing the web distraction-free. There were questions about support for more Kobo models. Some worried about security, but others explained that a reboot returns the device to normal, so it is safe to try. The SDK was praised for being easy, and some people wanted more games or offline Wikipedia. Many compared Cobalt to jailbreaking Kindles, saying Kobo is more open. Some users reminded others not to try this on unsupported devices.

Now, let’s look at science. Scientists have made the biggest 2D map of the universe, called the DESI Legacy Imaging Survey. This map has more than 5.6 trillion pixels and shows about 4 billion stars and galaxies, covering almost 75% of the sky in visible and near-infrared light. Anyone can use this map, from pro astronomers to citizen scientists. It helps people find special events like supernovae, rare things like gravitational lenses, and helps study dark matter and dark energy.

The map was made by joining 263,407 images from three big surveys—DECaLS, MzLS, and BASS—plus data from the WISE satellite. Over 160 scientists collected the data, and a smaller team built the final map. It is also used by the Dark Energy Spectroscopic Instrument (DESI) to pick targets for a 3D map of the universe. The project took a year to write code and eight weeks of supercomputer time to process all the images. The map will also help new telescopes and AI tools.

In the comments, people were amazed by the size and teamwork. Many said the data will help new discoveries and train AI to find patterns in space. Some talked about the need for big storage and computer power. Others shared links to the map viewer and encouraged everyone to explore. There were questions about future updates and memories of older sky surveys. Most people were excited and hopeful for what we can learn from this map.

Next, there is a story about someone who took control of special internet domains used to route phone calls, and by accident, logged hundreds of thousands of calls to military bases. The domains are part of ENUM, which turns phone numbers into DNS names for internet calls. The author bought an expired domain for 5 euros, getting routing control for Saint Helena, Diego Garcia, and Ascension Island—places with military bases. They thought nobody used it, but found lots of real traffic from American IP addresses to these bases. This means a bad actor could spy on calls. The author told the authorities, and the UK’s National Cyber Security Centre finally took action. The setup is still not fully fixed.

In the comments, people were amazed that such old systems are still in use for sensitive calls. Some called this “dependency rot”—systems relying on forgotten things. Others worried about how many other critical systems are open to similar attacks. Some joked about how easy the hijack was, and others praised the author for acting responsibly. Many noticed how hard it is to get big organizations to care about such risks, and some wondered if attacks like this are already happening. There was praise for the honest write-up, mixing humor and a real warning for tech workers.

Now, let’s talk about Claude Mythos 5, a new AI tool from Anthropic that helps find and fix software security problems. It is now available for more security teams, and there is a $35 million fund to help open-source projects. Claude Mythos 5 can scan code for bugs and suggest ways to fix them. Security teams use it through software they already know, not by talking to the AI directly. Anthropic puts limits on how people use it, so bad actors cannot use it for attacks. For example, you can get a patch for a bug, but not ask for hacking code.

The new fund gives free access to Claude for open-source security groups. The Cyber Verification Program is also growing, letting trusted teams use more features if they do real security work.

In the comments, people were happy to see strong AI tools for defense, not just attack. Some said focusing on open-source is important, since so many people depend on it. There were worries about risks: if the AI is powerful, attackers might find ways to use it. Some liked that humans must approve changes, but worried it might slow things down. Overall, people are hopeful but careful about new AI security tools.

Next, we look at DeepSeek-v4-flash-vision-exp, a model that lets you send both images and text. You can ask the model to describe pictures, read screenshots, or look at charts. It supports JPEG, PNG, GIF, and WebP. You can send images in three ways: base64 in your request, a web link, or upload with the Files API and use a file ID. There are size limits: up to 48 MiB direct or 200 MiB with a file ID, and each image up to 32 or 64 MiB. You can send up to 600 images in a request, but the largest side is 8192 pixels.

You can pick a detail level: “low” makes images smaller and faster, “high” or “original” keeps size, and “auto” picks the best. Only vision models accept images, and you can use DeepSeek with OpenAI or Anthropic API styles. Images are turned into tokens for processing.

In the comments, people liked the support for many formats and the OpenAI-compatible API. Others liked the three ways to upload images and the clear size rules. Some asked about privacy and security, and how DeepSeek handles user data. A few worried about request size limits, but others said Files API helps with big jobs. There were questions about speed, detail modes, and using more programming languages. People saw this as useful for reading receipts, checking screenshots, or working with images and AI.
